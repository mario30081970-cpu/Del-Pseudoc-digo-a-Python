2 Tus 3 Reglas de Oro

Tocá cada regla para ver el detalle. Son las tres únicas cosas que cambian entre PSeInt y Python.

1 Confiá en tu lógica: ya funciona ›

Tu algoritmo en pseudocódigo ya está resuelto. Python no te pide aprender a programar de nuevo: solo te pide aprender un nuevo vocabulario para ejecutar lo que ya sabés.

El pseudocódigo es tu plano teórico; Python es tu herramienta de construcción.

2 Los dos puntos : abren el bloque ›

El símbolo : reemplaza a Entonces y a Hacer. Es la señal que le dice a Python: “preparate, lo que sigue indentado pertenece a esta condición”.

Se usa en if, else, while y for.

3 Adiós FinSi: ahora manda la indentación ›

En PSeInt, palabras como FinSi o FinMientras eran paredes visibles que cerraban un bloque. Python elimina esas paredes y las reemplaza por 4 espacios al inicio de cada línea.

El bloque termina cuando la sangría vuelve atrás.

⚠️ La indentación NO es estética: es sintaxis obligatoria. Un solo espacio mal puesto produce IndentationError y rompe la ejecución del programa.

3 Reto 1 · La señal que falta

0 / 10

Este condicional fue traducido de PSeInt a Python, pero le falta la señal que abre el bloque y el print quedó desalineado. Corregilo y comprobá.

Pseudocódigo (PSeInt) 
Si edad >= 18 Entonces
    Escribir 'Eres mayor de edad'
FinSi
Tu código en Python
La línea del if debe terminar con dos puntos (eso reemplaza a “Entonces”). Y el print que está adentro del condicional debe empezar con 4 espacios. La palabra FinSi ya no existe: se borra.

    4 Reto 2 · IndentationError

    0 / 10

    Este programa produce un IndentationError: Python no sabe qué instrucciones pertenecen al if y cuáles al else. Arreglá la sangría.

    Código con error
    Colocá el cursor en una línea y usá el botón “Indentar 4 espacios” (o seleccioná varias líneas para indentarlas juntas). Las líneas else: y if ...: van al mismo nivel, sin espacios adelante. Todo lo de adentro lleva 4 espacios.
